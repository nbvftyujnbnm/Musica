# 🎵 Musica

コード進行とメロディーラインを直感的に選択していくと曲ができる、ブラウザで動く作曲ツールです。ビルド不要・依存ライブラリなしの HTML / CSS / JavaScript(Web Audio API)だけで動きます。

## 使い方

`index.html` をブラウザで開くだけです。ローカルサーバーを使う場合:

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 作曲の流れ

1. **キーとテンポを選ぶ** — 12キー × メジャー/マイナー、テンポ 40〜240 BPM、4/8/12/16小節。
2. **コード進行を選ぶ** — 王道進行・カノン進行・小室進行・丸サ進行・ジャズ2-5-1などのプリセットをワンタップで適用。小節をクリックすればダイアトニックコード(三和音/セブンス/sus4/add9)から1つずつ差し替えられます。
3. **メロディーを描く** — ピアノロール風グリッドをクリック/ドラッグで入力。**コードに合う音(コードトーン)が青くハイライト**されるので、音楽理論を知らなくても自然なメロディーが作れます。同じ高さのマスを並べると長い音に。「🎲 おまかせ生成」でコードに沿ったメロディーを自動生成することもできます。
4. **サウンドをカスタム** — 「バンド編成」プリセットをタップすれば各パートの音色がまとめて切り替わり、バンドサウンドに。そこから各パートの音色・スタイル・音量を細かく調整できます。
5. **再生・保存する** — その場でループ再生(スペースキーでも再生/停止)。MIDI・WAVファイルとして保存したり、共有リンクで作品を渡せます。

## 機能

### 作曲
- 🎹 スケール構成音だけのグリッドなので「外れた音」が出ない
- 🎨 小節ごとのコードトーンハイライトで、合う音がひと目でわかる
- 🎲 コード進行に沿ったメロディーの自動生成
- 🔀 スケールを切り替えても、今のコード進行を度数を保ったまま自動で移調

### バンドサウンド
メロディー・コード・ベース・ドラムの4パート構成で、生バンドのようなアンサンブルが鳴らせます。
- 🎚 **バンド編成プリセット**: ロックバンド / ポップスバンド / シティポップ / バラード / チップチューン / ジャズ・ラウンジ をワンタップで(作曲したコード・メロディーはそのまま)
- 🎤 **メロディー**: 音色8種(やわらか/シンセリード/ファミコン/ピアノ/エレピ/プラック/**エレキギター(クリーン・歪み)**)、3度下のハモリ追加
- 🎹 **コード**: 音色8種、スタイル6種(パッド/アルペジオ↑↓↕/8分・4分ストローク)
- 🎸 **ベース**: 音色5種(シンセ/**エレキベース**/サブ/プラック/チップ)、パターン5種(ルート/4分/ルート+5度/オクターブ/ウォーキング風)
- 🥁 **ドラム**: 6パターン + クラッシュシンバル(4小節ごと)とタム回しのフィル(フレーズの切れ目)、オープンハイハットのアクセント
- ✨ **空間とノリ**: リバーブ(残響)とスウィング(はねるノリ)、パートごとの音量バランス

歪みギターは WaveShaper による本物のディストーション処理を通しています。

### 書き出し・共有
- 💾 標準MIDIファイル(SMF)書き出し(DAWに読み込み可能)
- 🎧 WAVファイル書き出し(現在のサウンド設定そのままをオフラインレンダリング)
- 🔗 共有リンク: 曲の全設定をURLに埋め込んでコピー、開くだけで復元
- 📝 作品はブラウザ(localStorage)に自動保存

## 技術メモ

- 音声合成: Web Audio API。ADSRエンベロープ付きのマルチレイヤーオシレーター、ノイズ/サイン合成のドラム、生成インパルス応答によるコンボリューションリバーブ、コンプレッサーで音割れ防止
- WAV書き出し: `OfflineAudioContext` で高速レンダリングし、16bit PCM の WAV を生成
- MIDI書き出し: フォーマット0のSMFを純粋なJavaScriptで生成
- 共有: 曲データを Base64 で URL ハッシュに格納
- 外部リソースへのアクセスなし、完全にオフラインで動作
