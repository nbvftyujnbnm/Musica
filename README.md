# 🎵 Musica

コード進行とメロディーラインを直感的に選択していくと曲ができる、ブラウザで動く作曲ツールです。ビルド不要・依存ライブラリなしの HTML / CSS / JavaScript(Web Audio API)だけで動きます。

## 使い方

`index.html` をブラウザで開くだけです。ローカルサーバーを使う場合:

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 作曲の流れ

1. **キーとテンポを選ぶ** — 12キー × メジャー/マイナー、テンポ 60〜180 BPM、4小節または8小節。
2. **コード進行を選ぶ** — 王道進行・カノン進行・小室進行・丸サ進行などのプリセットをワンタップで適用。小節をクリックすればダイアトニックコード(三和音/セブンス)から1つずつ差し替えられます。
3. **メロディーを描く** — ピアノロール風グリッドをクリック/ドラッグで入力。**コードに合う音(コードトーン)が青くハイライト**されるので、音楽理論を知らなくても自然なメロディーが作れます。同じ高さのマスを並べると長い音になります。「🎲 おまかせ生成」でコードに沿ったメロディーを自動生成することもできます。
4. **再生する** — メロディー+コードパッド+ベースをその場で再生(ループ対応、スペースキーでも再生/停止)。**MIDIファイルとして保存**して DAW に読み込むこともできます。

## 機能

- 🎹 スケール構成音だけのグリッドなので「外れた音」が出ない
- 🎨 小節ごとのコードトーンハイライトで、合う音がひと目でわかる
- 🎲 コード進行に沿ったメロディーの自動生成
- 🔁 ループ再生・再生位置のリアルタイム表示
- 💾 標準MIDIファイル(SMF)書き出し
- 📝 作品はブラウザ(localStorage)に自動保存

## 技術メモ

- 音声合成: Web Audio API(メロディー=三角波、コード=ローパスをかけたノコギリ波パッド、ベース=サイン波、コンプレッサーで音割れ防止)
- MIDI書き出し: フォーマット0のSMFを純粋なJavaScriptで生成
- 外部リソースへのアクセスなし、完全にオフラインで動作
